# Online Book Store

## About the Project

Online Book Store is a database-based project designed to manage books, customers, and orders. The project uses SQL and PostgreSQL to store, organize, and retrieve book store information efficiently.

## Technologies Used

* PostgreSQL
* SQL
* pgAdmin 4

## Database Tables

### 1. Books

Stores information about books available in the store.

**Columns:**

* Book_ID
* Title
* Author
* Genre
* Published_Year
* Price
* Stock

### 2. Customers

Stores customer information.

**Columns:**

* Customer_ID
* Name
* Email
* Phone
* City
* Country

### 3. Orders

Stores information about customer orders.

**Columns:**

* Order_ID
* Customer_ID
* Book_ID
* Order_Date
* Quantity
* Total_Amount

## SQL Operations

The project includes SQL queries for:

* Creating databases and tables
* Inserting records
* Updating records
* Deleting records
* Retrieving data using SELECT
* Filtering data using WHERE
* Sorting data using ORDER BY
* Aggregate functions
* GROUP BY and HAVING
* JOIN operations
* Subqueries

## 🎯 Objective

The main objective of this project is to practice SQL and PostgreSQL database management through a real-world Online Book Store example.
